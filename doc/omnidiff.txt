1. Introduction                                        *omnidiff-introduction*

omnidiff.nvim renders diffs computed by the external `omnidiff` CLI
(https://github.com/ivankovic/omnidiff) directly in Neovim buffers, using
`omnidiff --mode json` for full-range-precision hunk data instead of parsing
ANSI text back out of a terminal-based diff tool.

==============================================================================
2. Requirements                                        *omnidiff-requirements*

* Neovim >= 0.10 (uses |vim.system()|).
* The `omnidiff` binary, on $PATH or pointed at explicitly (see
  |omnidiff-setup|), built with `--mode json` support. Run `:checkhealth
  omnidiff` to confirm both.

==============================================================================
3. Setup                                                      *omnidiff-setup*

>lua
    require('omnidiff').setup({
      -- Path to (or name of) the omnidiff binary. Default: 'omnidiff'.
      bin = 'omnidiff',
    })
<
`setup()` is optional - the defaults above are used if it is never called.

==============================================================================
4. Commands                                                *omnidiff-commands*

                                                                  *:OmniDiff*
:OmniDiff {before} {after}
    Diff two files and open them side by side in a new tab, each side
    highlighted with its own changes.

                                                              *:OmniDiffThis*
:OmniDiffThis
    Diff the current buffer's unsaved edits against the on-disk file. Does
    nothing (with a message) if the buffer has no unsaved changes.

==============================================================================
5. Highlights                                            *omnidiff-highlights*

omnidiff.nvim defines these highlight groups, linked (not hardcoded) to
standard diff highlights, so any colorscheme that already styles the
standard groups looks right immediately:

    OmniDiffInsert  -> DiffAdd
    OmniDiffDelete  -> DiffDelete
    OmniDiffUpdate  -> DiffChange
    OmniDiffMove    -> DiffText

Override any of them as you would any other highlight group, e.g.:
>lua
    vim.api.nvim_set_hl(0, 'OmniDiffMove', { fg = '#e5c07b' })
<
